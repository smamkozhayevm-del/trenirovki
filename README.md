# Тяни — Толкай — Плыви

Личный дневник тренировок: зал, бассейн и сон. Устанавливается на Android как приложение и работает без интернета.

**Адрес:** https://smamkozhayevm-del.github.io/trenirovki/

## Расписание

| День | Тренировка |
|---|---|
| Пн | Тяни A (зал) |
| Вт | Бассейн |
| Ср | Толкай A (зал) |
| Чт | Бассейн |
| Пт | Тяни B (зал) |
| Сб | Бассейн |
| Вс | Толкай B (зал) |

## Что умеет

- **Зал:** вес и повторы по подходам, разный вес по подходам, суперсеты, анимации упражнений и схема мышц, редактор плана, подсказка «пора добавить вес».
- **Бассейн:** выбор «В удовольствие» или «Тренировка». Для тренировки записываются вся дистанция, баттерфляй и лягушка, у каждого отметка «без остановки» или «с остановкой».
- **Сон:** первый блок каждого дня — сколько спал и во сколько проснулся, плюс среднее за 7 дней.
- **Неделя:** дни с галочками, сегодняшний день подсвечен зелёным, счётчик «N из 7».
- **Графики:** объём подходов на мышцы за неделю, прогресс по упражнению, метры в бассейне.
- **Достижения:** рекорды, тоннаж, серии недель, заплывы.
- **Резервная копия:** CSV-файл со всеми записями, планом, бассейном и сном. Открывается в Excel и загружается обратно.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | Вся программа: разметка, стили, код и встроенный Chart.js |
| `manifest.webmanifest` | Название, иконки и цвета для установки на телефон |
| `sw.js` | Работа без интернета: кэширует файлы приложения |
| `icon-192.png`, `icon-512.png`, `icon-maskable.png` | Иконка: красные следы когтей на чёрном |

## Где хранятся записи

Только на телефоне, в памяти Chrome для этого сайта. На GitHub лежит одна программа, без записей. Если очистить данные Chrome, записи пропадут, поэтому раз в 1–2 недели нужно скачивать CSV-копию и сохранять её в Telegram или Google Диск.

## Как обновить программу

1. В приложении скачать свежую CSV-копию.
2. В репозитории нажать **Add file → Upload files** и загрузить изменённые файлы с теми же именами.
3. Нажать **Commit changes** и подождать 1–2 минуты.
4. Открыть приложение с интернетом. Если вид старый, закрыть приложение полностью и открыть снова.

Чтобы попросить изменения в новом чате с Claude, приложи файл `index.html` (скачай его из репозитория: открой файл → кнопка скачивания) и вставь текст ниже, дописав в конце, что нужно изменить. Если меняются иконки, манифест или `sw.js`, приложи и их.

```text

https://smamkozhayevm-del.github.io/trenirovki/). Прикладываю index.html.
Внеси изменения, которые я опишу в конце, и верни полный файл целиком.

Как устроено:
- Один файл index.html: разметка, CSS, ванильный JS внутри одной IIFE,
  Chart.js 4.4.1 встроен прямо в файл. Без сборки и внешних библиотек.
- Рядом лежат manifest.webmanifest, sw.js (network-first кэш, константа
  CACHE = "trenirovki-vN") и иконки icon-192.png, icon-512.png,
  icon-maskable.png.
- Приложение должно работать полностью офлайн: никаких внешних шрифтов,
  CDN и сетевых запросов.
- Дизайн: всегда тёмная тема (html data-theme="dark"), почти чёрный фон

  сегодняшний день подсвечен зелёным #3DDC84, сделанные дни отмечены
  зелёной галочкой. Цвета типов: тяни — синий (--pull), толкай — красный
  (--push), бассейн — бирюзовый (--swim).
- Неделя (массив DAYS по порядку дней): Пн pullA «Тяни A», Вт poolTue
  «Бассейн», Ср pushA «Толкай A», Чт poolThu «Бассейн», Пт pullB «Тяни B»,
  Сб poolSat «Бассейн», Вс pushB «Толкай B». Дни бассейна имеют
  kind:"pool" и пустой список упражнений.

Данные (НЕ ломать совместимость, у меня уже есть записи):
- localStorage: "log" (все записи), "plan" (изменённый план по id дня),
  а также "day", "pw", "viz", "pick", "lastBackup".
- Внутри "log" записи по ключам:
  • зал: "s_ГГГГ-ММ-ДД_<idДня>" → {day, date, ex:{"Название":
    {w:"вес", r:["повторы"...], ws:["вес по подходам"...]}}, ts}
  • бассейн: "s_ГГГГ-ММ-ДД_poolTue|poolThu|poolSat" → {day, date,
    pool:{mode:"fun"|"train", total, totalStop, fly, flyStop, breast,
    breastStop}, ts}, где *Stop = "nonstop" | "stop" | ""
  • сон: "s_ГГГГ-ММ-ДД_sleep" → {day:"sleep", date, sleep:{h, m, wake:"ЧЧ:ММ"}}
- Резервная копия CSV (разделитель ;): строки упражнений + служебные
  строки "#БАССЕЙН", "#СОН", "#ПЛАН" с JSON во втором столбце. Новые
  данные тоже добавляй в копию и в восстановление из неё.
- Записи упражнений привязаны к названию упражнения.

Правила для изменений:
- Не меняй формат и ключи существующих данных. Если нужно новое поле,
  добавь его так, чтобы старые записи продолжали работать.
- Проверь, что после изменений нет ошибок в консоли, всё работает офлайн
  и нормально выглядит на ширине телефона (~390 px).
- В конце напиши коротко, что изменилось, и какие именно файлы мне нужно
  перезалить на GitHub. Если менялись файлы кроме index.html, увеличь
  номер CACHE в sw.js.

Что нужно изменить:
[опиши здесь]
```
